Upload any of them on the live demo (or pick them under the samples, as "Same measurement, other file formats"): every one except *Other column names* gives exactly the sample's result, and that one does once you match its columns on the page. Made by `data/make_examples.py` from `data/seeded/`; `eval/check_parsing.py` checks them.
