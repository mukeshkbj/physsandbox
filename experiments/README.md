## Example upload files

Every experiment's folder holds its headline sample saved the ways real files arrive. Upload any of them on the [live demo](https://192-248-159-149.sslip.io/), or pick them on the page under the samples (*Same measurement, other file formats*). Every file except *Other column names* gives exactly the sample's result, and that one does once you match its columns on the page.

| File | Format |
| --- | --- |
| `excel_export.csv` | **Excel export**: Byte-order mark, Windows line endings, comment lines padded with commas, an empty row of only commas above the header, a trailing empty column |
| `semicolon_decimal_comma.csv` | **Semicolons, decimal commas**: A European spreadsheet export: `;` between columns and `0,25` for 0.25 |
| `tab_separated.tsv` | **Tab-separated**: Tabs between columns, as copied out of a spreadsheet |
| `unicode_text.txt` | **UTF-16 "Unicode text"**: Excel's *Unicode text* export: UTF-16 with a byte-order mark, tab-separated |
| `other_column_names.csv` | **Other column names**: The names a person would type, units in brackets (`Current (A)`): the page asks you to match them |

Everything here is written by [`data/make_experiments.py`](../data/make_experiments.py) from the catalogue (`app/catalog.yaml`, `app/catalog.d/`), the fault libraries (`faults/`) and the physics code, so it matches what runs. [`eval/check_parsing.py`](../eval/check_parsing.py) checks that every example file gives the sample's result.
